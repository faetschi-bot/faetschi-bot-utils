# Security Policy

## Supported versions

Each tool in this repo is versioned and released independently, and only its
latest release is supported. Current versions are shown in the
[tools table](./README.md#tools) and on the
[Releases](https://github.com/faetschi-bot/faetschi-bot-utils/releases) page.

## Reporting a vulnerability

Please **do not** open a public issue for a security problem.

Use GitHub's private vulnerability reporting:
[**Report a vulnerability**](https://github.com/faetschi-bot/faetschi-bot-utils/security/advisories/new).

If that button is unavailable, open a short issue asking for a private channel —
without exploit details or the affected code — and a maintainer will follow up.

Please include, when you can:

- the affected tool and version,
- a minimal reproduction or proof of concept,
- the impact you believe it has.

This is a volunteer project, so there is no guaranteed response time. We will
acknowledge reports as soon as we can and coordinate a fix and disclosure with
you.
